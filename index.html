WorkBuddy + DeepSeek V4.1 Flash
小白使用指南

已经有 WorkBuddy？从这里开始，不折腾复杂环境，也能把 DeepSeek 用起来。

我已经有 WorkBuddy，直接开始 主线：选模型 → 试第一句 → 常用场景 我想了解 DeepSeek 自接 API、计费注意、Key 安全 我以后主要想写代码 进阶：PI-Desktop / Harness（都非必须）

点一个最像你的情况：

① 已内置怎么用

WorkBuddy 已经内置 DeepSeek（Flash / Pro 档）。日常办公直接用内置即可，不必先去申请 API。

  1. 打开 WorkBuddy。
  2. 在模型列表里选 DeepSeek 的 Flash / 速度档。软件里可能显示成 Deepseek-V4-Flash，以你界面上的名字为准。
  3. 模式档位不确定就选 「均衡」 起步；简单润色可用「快速」，很难的长任务再用「极致」。
  4. 上下文窗口别一上来开到最大，窗口越大越费积分。
内置 vs 自己接 API 内置：走 WorkBuddy 自己的积分 / 套餐。自接：走你 DeepSeek 账户账单；API Key 只保存在你本机，不上传云端。
下一步：第一次用 我要自己接 API

② 自接 API 配置

优先用界面：设置 → 模型 → 添加自定义模型。小白不必先改文件。

界面里填什么

项填法
URLhttps://api.deepseek.com/v1/chat/completions
模型名deepseek-flash（对应 V4.1-Flash）
API Key你自己的 Key；本教程只写占位符 YOUR_DEEPSEEK_API_KEY

旧教程里的 deepseek-v4-flash 多半仍可用，但请优先用新名 deepseek-flash。Pro 用 deepseek-v4-pro（易变，新手不必追）。

可选：环境变量（进阶）

setx DEEPSEEK_API_KEY "YOUR_DEEPSEEK_API_KEY"

然后在配置里把 Key 写成引用：

"apiKey": "${DEEPSEEK_API_KEY}"
改完配置要完全退出再打开 WorkBuddy 若必须手改 models.json：在用户目录下搜索该文件，常见文件夹是 .workbuddy 或 .codebuddy，以你本机实际为准。请用 UTF-8（无 BOM）保存。

申请 Key：打开 DeepSeek 开放平台 API Keys（需登录）→ 新建 → 立刻复制保存。

下一步：第一次用 先看防烧钱

③ 第一次用

  1. 打开 WorkBuddy，选好 DeepSeek Flash（或界面等价名字）。
  2. 模式选「均衡」。
  3. 在对话框输入一句简单请求，例如：「用三句话介绍你自己，并告诉我现在用的是哪个模型。」
  4. 能正常回复，就说明主线通了。

常见故障

401 多半是 API Key 抄错，或把网址填进了 Key 栏。重新核对 Key。
404 / Model Not Found 模型名写错或带了多余空格。自接时请精确填写 deepseek-flash。
配置不生效 检查 JSON 是否合法、是否带了 UTF-8 BOM、以及是否已完全重启 WorkBuddy。

下一步：FAQ

⑤ FAQ

API Key 是什么？
可以把它理解成你账户的「钥匙」：程序用它证明「请求是你发的」。它像密码——不能发群、不能截图公开、不能提交到 GitHub。本教程里只写占位符 YOUR_DEEPSEEK_API_KEY，请换成你自己在 DeepSeek 开放平台创建的 Key。
配置后为什么不生效？
常见原因：JSON 写坏了、文件用了带 BOM 的编码、或者改完没有完全退出再打开 WorkBuddy。自接时再核对 URL、模型名 deepseek-flash、Key 是否填对栏位。优先用设置界面添加模型，比手改文件更稳。
长任务循环怎么办？
Agent / 长任务会多次调用模型，Token 和积分消耗明显高于单次聊天。先做短任务；内置看 WorkBuddy 额度，自接盯 DeepSeek 账单。若它一直转圈，先停掉任务，缩小范围再试。Harness、PI-Desktop 都非必须，办公日常继续用 WorkBuddy 即可。
1. WorkBuddy 里怎么找到 DeepSeek？
打开模型列表，选 DeepSeek 的 Flash / 速度档。界面可能显示 Deepseek-V4-Flash，以软件为准。没有的话再走「自接 API」。
2. 内置模型和自己接 API 有什么区别？
内置走 WorkBuddy 积分；自接走你 DeepSeek 账单。自接时 Key 只存在本机。
3. Model ID 应该填什么？
自接统一填 deepseek-flash。旧名 deepseek-v4-flash 多半仍可用，优先新名。Pro 用 deepseek-v4-pro（易变）。
4. Base URL 填什么？
https://api.deepseek.com/v1/chat/completions
5. API Key 在哪里创建？
到 platform.deepseek.com/api_keys 登录后新建。教程里只会出现 YOUR_DEEPSEEK_API_KEY。
6. 出现 401 怎么办？
Key 不对，或把 URL 填进了 Key 栏。重新复制 Key 并确认填对栏位。
7. 出现 404 或 Model Not Found 怎么办？
模型名写错。请精确使用 deepseek-flash，去掉多余空格。
8. Flash 和 Pro 怎么选？
新手优先 Flash。Pro 更贵且政策易变，默认不必追 Pro。
9. 会不会很贵？怎么防烧钱？
内置看 WorkBuddy 积分；自接看 DeepSeek 账单。少开超大上下文、少跑超长 Agent 任务。价格以官网当天为准（易变）。详见「⑧ 安全与防烧钱」。
10. models.json 在 Windows 的哪个路径？
优先用设置界面。非要改文件：在用户目录搜索 models.json，常见 .workbuddy / .codebuddy，以本机实际为准；UTF-8 无 BOM，改完完全重启。
11. 要不要装 Node / 命令行？
WorkBuddy 主线不需要。只有自己玩 Harness 官网 npx 路径时才需要 Node。
12. 什么时候才需要 PI-Desktop？
办公继续用 WorkBuddy。以后主要写代码、要更强多模型 Agent，再考虑 PI-Desktop。它是 Early Preview，且非必须。
13. DeepSeek Harness 必须装吗？
不必。 它是官方公测 Agent 工作台。想体验按官网 npx @deepseek-ai/dsh web；不要下不明 exe。
14. 我需要 Codex / ChatGPT 吗？
不必。本教程主线是 WorkBuddy + DeepSeek。不必为了本教程再装 Codex、ChatGPT、Harness 或 PI。
15. 深色模式怎么开？
点本页右上角月亮 / 太阳按钮，选择会记住。
16. 代码块怎么复制？
点代码右上角「复制」。
17. Key 可以发给同事帮忙排查吗？
不可以。 Key 当密码：不进群、不进截图、不进 GitHub。泄露了就去平台作废并换新。

⑥ 何时装 PI-Desktop

非必须。 已经会用 WorkBuddy 办公的小白，可以完全跳过本章。

  • 官方仓库：vastsa/PI-Desktop
  • Windows 有安装包和 zip；用官方包不需要装 Node / Rust / pnpm
  • 状态：Early Preview
  • 可通过 OpenAI 兼容方式接入 DeepSeek（填地址 + deepseek-flash + Key）
适合谁 以后主要写代码、想要更强 Agent / 多模型时再考虑。日常办公请继续 WorkBuddy。

文档：pi-docs.aiuo.net · 下载：Releases

下一步：Harness 是什么

⑦ Harness 是什么

DeepSeek 官方的 Agent 工作台（公测 / Preview）。不是 WorkBuddy 必装项。

进阶体验请按官网路径（需要先会装 Node）：

npx @deepseek-ai/dsh web
注意 不要下载来路不明的 exe。长任务会多次调用模型，Token 消耗明显高于单次聊天。

官网：deepseek.com/zh/harness · 仓库：deepseek-ai/deepseek-harness
